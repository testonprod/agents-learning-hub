        Memory · state · storage
        
      
        Stateless agent, stateful conversation.
        
      
        Any instance can serve the next turn, so memory lives outside the process. There are three layers: storage, state management and TurnState.
        
    
        
    
        
    
        
    
        
    
        !
        Where does “AI memory” live? The SDK doesn't have a separate memory module. Chat history for your orchestrator is something you put in conversation state. For example, Semantic Kernel's ChatHistory is read from turnState.Conversation. Long-term knowledge such as retrieval or vector search belongs to the AI layer you bring.
        
  
        

  
  
        
    
        
      
        Identity & auth
        
      
        Three identities, never mixed up.
        
      
        The agent proves who it is. The user signs in. In agentic scenarios, the agent can also act with its own Entra Agent ID. Each one has its own module.
        
    
        
    
        
    
        
      
        
      
        
        
        OAuth: auto sign-in or per route?
        
        
        
        
        Rule of thumb: read the user token as late as possible in the handler, so the SDK can refresh it if it's close to expiry.
        
      
        
    
        
  
        

  
  
        
    
        
      
        Bring your own brain
        
      
        The SDK carries the message. You choose the mind.
        
      
        The Agents SDK never decides what to say. It hands your handler a turn, and you call whatever orchestrator and model you like.
